# Visual identity

**Slotiva — horários livres que viram encontros.**

The name combines “slot”, an available time, with “ativa”, suggesting an active
agenda. The logo references a leaf/tree and star.

| Variant | Use |
| --- | --- |
| Symbol + slotiva + tagline | Home page and presentations |
| Symbol + slotiva | Application header |
| Symbol only | Favicon and mobile icon |

Preserve proportions and use the symbol at small sizes. Check contrast,
legibility at 16/32 pixels and an accessible name for the home link.

Exported logo assets still need to be integrated into the application.
